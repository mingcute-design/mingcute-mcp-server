- Update to Free 3.1.0: 2,263 icon identities and 4,526 verified SVG variants.

- Compile JavaScript for publishing; remove the runtime TypeScript loader. Require Node.js 22.12+.
- Update dependencies and add PR CI, reproducible catalogue checks, and fresh packed-server integration checks.
